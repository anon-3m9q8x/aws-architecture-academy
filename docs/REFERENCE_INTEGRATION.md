## Architecture Labから

- 全選択肢の理由と公式出典を持つNQ20問を追加。元の40問は同じIDのまま保持し合計60問（47択一・13複数）。追加20問のIDはlab-n01等に名前空間を分ける。元資料のapproved表示は継承せず、専門家レビュー未実施と表示。
- VS_*の構成10シーンを既存プレイヤー形式に変換。従来3件を保持して計13シーン。元のvia経路を引き継ぎ、途中のエッジもハイライト。
- 元サイトの全シミュレーター、障害ラボ、隠しルール、管理画面、旧問題全件、比較用同期プレイヤーは移植していない。今回取り込んだ範囲と混同しない。
