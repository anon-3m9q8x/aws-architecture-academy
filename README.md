# AWS Architecture Academy

日本語の AWS 資格学習ワークスペース。依存パッケージ不要の HTML / CSS / JavaScript 製です。

公開サイト: https://anon-3m9q8x.github.io/aws-architecture-academy/

## 学習機能

- 学習ノート107項目: 目的・機能・使いどころ・比較67組・関連269件。検索、学習済み、お気に入り、個人メモ、JSONバックアップ・非破壊の取り込み。AWSサービス以外にリソース・一般概念も含みます。
- 従来の図鑑42項目: AWSサービス・関連項目40件＋一般概念2件。カテゴリ・キーワード検索。S3 Glacier は独立サービスではなくストレージクラスとして分類。
- 学習演習60問: 単一選択47問・複数選択13問、全選択肢の解説と公式ドキュメントへの参照。CLF/SAAを中心に、添付LabのDVA/SAP関連問題も含みます。資格レベルは教材上の目安で、公式試験問題ではなく全試験範囲の網羅を保証しません。専門家レビュー未実施。
- 出題フィルター: 資格レベル・分野・難易度・未回答・直近誤答、5問・10問・該当全問。出題順はセッションごとにシャッフル。
- 学習モード: 各問で回答後に採点と解説を表示。複数選択は正解集合との完全一致で判定。試験スコアへの換算は行いません。
- 回答回数、全回答ベースの正答率、分野別成績、直近の誤答に基づく復習対象。セッション中断時も提出済み回答は保持しますが、未提出の回答はページの再読み込みで失われます。
- 従来の3教材に、添付Labの10教材を追加した13シーン。再生・停止・前後・先頭・速度・シーク。
- 参考画像に寄せた3列のホーム、白・淡いブルー・丸いカード・写真のヒーロー。実回答に基づく直近7日間の回答数。ライト表示のみ(ダークモードは廃止)、モバイル対応。

- **全 13 資格・15 試験**(2026-11-06 時点の公式試験ガイド): CLF-C02 / AIF-C01 / AIB-C01 / SAA-C03 / SOA-C03 / DEA-C01 / DVA-C03・C02 / MLA-C02 / SAP-C03・C02 / DOP-C02 / AIP-C01 / ANS-C01 / SCS-C03。旧版(DVA-C02・SAP-C02)は受験期限を表示。分野と配点は `data/exams.js`。

- **難易度と出題確率**: 問題ごとに難易度(★1〜4)と「出題確率(推定)」を表示。確率 = 1 − e^(−採点問題数 × 分野の配点比率 × 論点の重み)。AWS は問題ごとの出題率を公開していないため、試験ガイドの配点から計算した目安と明記。
- **絞り込み**: 資格(試験)・試験ガイドの分野・出題確率(高 / 中 / 低)・難易度・未回答 / 誤答で出題。資格を選ぶと分野ごとの配点・問題数・確率の内訳を表示し、分野をクリックで絞り込み。

## Edition 05 — サービス連携に重きを置いた資格学習サイトへ

- 方針: AWS 認定(SAA / SAP)で問われる「どのサービスを、どうつなぐか」を中心に再構成。参考: AWS Architecture Lab / AWS設計トレーナー。
- **サービス構築問題**(`#build`, 17 問): 要件を読み、パレットのサービスをキャンバスに配置し、2 つを順にタップして連携。採点(必要な部品・必要な連携・不要なサービス)、段階ヒント、模範解答のアニメーション再生とキャンバスへの反映。進捗はブラウザに保存。
- **サービス図鑑を 202 サービスに拡充**(学習ノート 107 項目 + 追加 95 サービス、AWS の主要カテゴリ 16 分類)。各サービスに公式ドキュメントを基にした定義文と公式ドキュメントへのリンク。学習ノートの目的・機能・使いどころ・試験のポイント・「この言葉が出たら」・比較を統合し、主要な組み合わせ約 80 件に「つながり方/必要な設定・権限/試験の視点」の詳細解説。
- **図鑑とアニメーションを統合**: カードをタップするとサービスの解説ページ(`#services/<id>`)へ。ページ上部で連携アニメーション(全サービスに自動生成+関連する連携シナリオ+構築問題の模範解答)を再生。連携カードの「この連携を再生」でその場面へ移動。従来の 13 教材は「連携シナリオ」タブへ移動(`#animation/<id>` は自動で転送)。
- **アニメーションの刷新**(`flow.js`): 曲線の経路、光の尾を引くパケット、イージング、到着時の拡大と波紋、流れる破線、吹き出しのスライド、1 本の requestAnimationFrame による連続再生(速度変更・一時停止・シークで途切れない)、表示範囲の自動調整。
- **選択表示スライド**: 図鑑のカテゴリ、一覧/シナリオ切替、詳細ページのセクションタブ(スクロールに連動)、アニメーション選択、構築問題のレベル切替で、選択中の背景がスライド。
- **背景の透過**: サイドバー・上部バー・パネルを半透明のガラス表現にし、背景のグラデーションと写真がうっすら見えるように。
- **削除**: ロードマップ、学習履歴、お気に入り(ノートのハートボタンを含む)。演習の分野別成績は資格問題演習ページに残しています。

## 保存データ

ブラウザのlocalStorageを使用します。端末間同期はありません。設定は `aaa.ui.preferences.v1`、既存のアニメーション履歴は `aaa.step1.progress.v1` を維持。問題の回答は `aaa.practice.attempts.v1`、個人ノート・お気に入り・学習済みは `aaa.notebook.v1` に保存します。メモは自動保存、テーマ変更で消えません。別端末への移動はノートのバックアップファイルを利用します。利用不可時はタブ内のメモリで動作し、警告します。
