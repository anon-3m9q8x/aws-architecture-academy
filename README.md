# AWS Architecture Academy

日本語の AWS 資格学習ワークスペース。依存パッケージ不要の HTML / CSS / JavaScript 製です。

公開サイト: https://anon-3m9q8x.github.io/aws-architecture-academy/

## 学習機能

- 学習ノート107項目: 目的・機能・使いどころ・比較67組・関連269件。検索、学習済み、お気に入り、個人メモ、JSONバックアップ・非破壊の取り込み。AWSサービス以外にリソース・一般概念も含みます。
- 従来の図鑑42項目: AWSサービス・関連項目40件＋一般概念2件。カテゴリ・キーワード検索。S3 Glacier は独立サービスではなくストレージクラスとして分類。
- 学習演習60問: 単一選択47問・複数選択13問、全選択肢の解説と公式ドキュメントへの参照。CLF/SAAを中心に、添付LabのDVA/SAP関連問題も含みます。資格レベルは教材上の目安で、公式試験問題ではなく全試験範囲の網羅を保証しません。専門家レビュー未実施。
- 出題フィルター: 資格レベル・分野・難易度・未回答・直近誤答、5問・10問・該当全問。出題順はセッションごとにシャッフル。
- 学習モード: 各問で回答後に採点と解説を表示。複数選択は正解集合との完全一致で判定。試験スコアへの換算は行いません。
- 回答回数、全回答ベースの正答率、分野別成績、直近の誤答に基づく復習対象。セッション中断時も提出済み回答は保持しますが、未提出の回答はページの再読み込みで失われます。
- 従来の3教材に、添付Labの10教材を追加した13シーン。再生・停止・前後・先頭・速度・シーク。
- 参考画像に寄せた3列のホーム、白・淡いブルー・丸いカード・写真のヒーロー。実回答に基づく直近7日間の回答数。ワンクリックのダーク／ライト切替、OS連動、モバイル対応。テーマ切替で回答や再生位置を初期化しません。

## Academy Edition / 04 の改良

- 名称を「AWS Architecture Academy」に統一（ブランド・フッター・版表記）。
- 画面操作: 左ナビの選択表示がスライド、☰でサイドバー開閉（状態を保存）、検索候補（↑↓・Enter・Esc、`/`キーで検索へ）、通知トースト、ホームに「前回の続きから」。
- 問題演習: 上部固定の問題マップ（正解・不正解・未回答・これからを色分け、21問以上は2段、押すと移動）、未回答へのジャンプ、前後移動・あとで解く、結果画面から各問の見直し・間違えた問題だけ再挑戦、キーボード操作（A〜F／1〜6で選択、Enterで確認・次へ、←→で移動）。
- 解き方: 全60問に「決め手 → 考える手順 → ひっかけ」（`data/solve.js`）。回答後に選択肢へ正解／あなたの回答／選ぶべき正解を表示し、関連ノートへのリンクを出す。
- 学習ノート: 主要50サービスに「この言葉が出たら／選ばないとき」（`data/cues.js`）、関連サービスの放射状ミニ図、そのサービスが出る問題の一覧とまとめて出題、前後のノート移動、一覧の選択表示スライドと自動スクロール・↑↓キー。
- アニメーション: 図を作り直し、ノードの種類別アイコン・矢印・経路ラベル、通信パケットが経路を移動、処理・判定の波紋、異常ノードの表示、メトリクス表示、ステップの色分けタイムラインとステップ一覧（クリックで移動）、教材チップ、Space／←→／Homeのキー操作、スマホでは図を横スクロール。
- サービス図鑑: カテゴリをボタンで切替、カテゴリ色、対応する学習ノートへのリンク。

## 起動

```sh
cd /workspace/aws-architecture-academy
python3 -m http.server 3300 --bind 127.0.0.1
```

JSON／ES Modulesを使うため、ファイルの直接オープンではなくHTTP経由で利用します。

## 保存データ

ブラウザのlocalStorageを使用します。端末間同期はありません。設定は `aaa.ui.preferences.v1`、既存のアニメーション履歴は `aaa.step1.progress.v1` を維持。問題の回答は `aaa.practice.attempts.v1`、個人ノート・お気に入り・学習済みは `aaa.notebook.v1` に保存します。メモは自動保存、テーマ変更で消えません。別端末への移動はノートのバックアップファイルを利用します。利用不可時はタブ内のメモリで動作し、警告します。

## 検証

サイト本体に追加依存はありません。ブラウザ検証にはPythonのPlaywrightとChromiumを使用します。ポート3300で起動してから実行してください。

```sh
node --check script.js
node --check practice.js
python3 docs/browser-check.py
python3 docs/browser-edge-check.py
python3 docs/check-sources.py
python3 docs/notebook-check.py
```

最新の検証結果は `docs/STUDYHUB_REPORT.md`、取り込み元と実装範囲は `docs/REFERENCE_INTEGRATION.md` を参照してください。`docs/LEARNING_EDITION_REPORT.md` は前回更新の記録です。以前のStep 1の結果は `docs/TEST_REPORT.md` に履歴として残しています。
