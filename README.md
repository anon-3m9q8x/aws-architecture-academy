# AWS Architecture Academy

日本語の AWS 資格学習ワークスペース。HTML / CSS / JavaScript と、同梱した公式Supabase SDKで動作します。

公開サイト:
- GitHub Pages: https://anon-3m9q8x.github.io/aws-architecture-academy/
- Render: https://aws-architecture-academy.onrender.com/ （リポジトリ直下の `render.yaml` で静的サイトとして公開。main への push で自動更新）

どちらも同じコードですが、学習データの保存先はブラウザごとに分かれます。アカウントでログインすると、Supabase 経由で同じ内容を共有できます。

## アカウントログイン・学習同期

NutriPathと共通のメールアカウントでログインし、学習メモ・学習済み・演習の回答履歴・構築問題の進捗と配置を端末間で共有できます。
**初回はSupabaseにAcademy専用SQLを実行し、認証のRedirect URLを追加してください。[設定手順](ACCOUNT_SETUP.md)**
DB準備が済むまでは `config.js` の `enabled: false` により従来の端末内保存で動作します。

## Edition 10.8 — 用語集(問題に出てくる専門用語の詳しい解説)

- 問題文・選択肢・解説から専門用語を抜き出し、408 語の詳しい解説を作成(`data/glossary-data.js`、仕組みは `glossary.js`)。各語: 一言の説明・解説・AWS での使われ方・試験のポイント・構成する用語・関係するサービス。
- 複合語は構成要素も解説(例: LLM-as-a-judge → LLM・ヒューマンインザループ)。構成する用語・「この用語を含む用語」・関係するサービスへダイアログ内で移動でき、「← 戻る」で戻れる。
- 資格問題演習の問題文・解説で、用語に紫の点線を付け、クリックで解説を開く(1 問の中で各用語の最初の 1 回だけ)。サービス名の図鑑リンクとは重ならないようにした。
- サービス図鑑に「用語集」タブを追加(分野で絞り込み・検索)。`#services/term:<id>` で直接開ける。
- 一般的な言葉で別の意味にも使われる別表記(「保持」「ブロック」「ツール」など)は、誤って一致しないよう対象から外した。

## Edition 10.7 — 図鑑の類似サービスを補充

- Aurora DSQL: Aurora(グローバルデータベース・Limitless)・DynamoDB との比較、CockroachDB・YugabyteDB・Cloud Spanner・TiDB、種類・発展形に「分散 SQL としての位置づけ」「グローバルデータベース・Limitless との違い」。
- 類似サービスの解説が無かった 150 サービスすべてに、AWS 内の比較(計 251 件)と、よく比較される AWS 以外のサービス(計 190 件)を追加。新しいサービス・他社の製品名は、仕様の細部を断定しない書き方にしている。

## Edition 10.6 — 図鑑「ブルー/グリーンデプロイ」

- サービス図鑑に「ブルー/グリーンデプロイ」(id: `bluegreen`、カテゴリ: 開発者ツール)を追加。AWS の単独のサービスではなく、CodeDeploy・ECS・Elastic Beanstalk・RDS・ALB・Route 53 などで実現するデプロイ手法として解説。

## Edition 10.5 — 上級チャレンジ(試験より難しい問題・別枠)

- 資格問題演習の種類に「上級チャレンジ」を追加。13 資格・各 20 問（計 260 問）、試験の想定レベルより一段難しい専門的な問題（複数のサービスの制約が絡む設計、拮抗するトレードオフ、障害の根本原因の特定など）。2 つ選ぶ問題を含む。
- 通常の問題とは別枠: 問題データは `data/expert/all.js`（`data/expert-questions.js` で通常の問題と同じ形に整え、`kind: "expert"`）。資格ごとの実施数・学習計画・前日の復習・成績の集計には含めない。資格・分野・出題モードで絞り込める（出題確率と実試験形式は対象外）。
- 問題には「上級チャレンジ · 試験より難しい」「難易度 ★★★★ 上級」と、難しいポイントを表示。不正解の選択肢には「選んだらまずい度」（`data/badness/<試験コード>.json` に統合）。
- 選択肢の順番は問題 ID から決まる順に並べ替え、正解の位置が偏らないようにした。

## Edition 10.4 — 前回の演習にアクセス

- 資格問題演習を終えたとき（結果を見た・終了した）に、出題した問題と結果を保存キー `aaa.practice.last.v1`（新しい順に 5 回分、アカウント同期）に保存。回答が 1 問もない演習は保存しない。
- 設定画面に「↩ 前回の演習」を表示。日時・問題数・正解／不正解を示し、「同じ問題をもう一度」「不正解だけ」「未回答だけ」で再演習。開くと問題の一覧（○×－）が出て、1 問ずつ開き直せる。2〜5 回前の演習にも切り替えられる。

## Edition 10.4 — 今日のプランの出題数を選べるように

- 学習計画の「今日のプラン」と「追加の目標」の「はじめる / 取り戻す / 挑戦する」の横に出題数の選択（残り全部・5・10・15・20・30・50 問、残りより少ない数だけ表示）を追加（`plan.js` の goBox）。
- 選んだ数は `aaa.plan.v1` の pick に保存（アカウント同期）し、次回以降の初期値になる。「もう少し」も選んだ数で出題（未設定なら従来どおり目標の 1/3・最低 5 問）。

## Edition 10.3 — 一日の目標を達成したら追加の目標

- 学習計画で今日の課題をすべて達成すると、「追加の目標」を自動で作成（`plan.js` の bonus）。候補は①前日の復習の残り ②苦手な分野の強化（3 問以上解いて正答率 8 割未満の分野、正答率の低い順）③明日以降の新しい問題の先取り。候補が無いときは総合演習。
- 追加の目標をすべて達成すると次の段階の目標を作る（1 日 5 段階まで）。進み具合は目標を作った時点からの回答で数え、「挑戦する」から該当する問題で演習を開始。段階は `aaa.plan.v1` の log[日付].bonus に保存（アカウント同期）。
- ホームの「今日の学習プラン」にも、目標の達成と残りの追加の目標を表示。

## Edition 10.2 — 学習時間と振り返りを自動化

- 学習計画の「今日のプラン」の学習時間を自動に（`report.js`）。回答した時刻の間隔を合計し、10 分以上あいたら別の学習として区切って 1 問目の時間を足す。カレンダー・連続学習日数もこの値を使う。
- 振り返りを自動で作成。その日の回答数（新しい問題・解き直し）・正答率・学習時間、直近 7 日の平均との比較、計画の達成度、分野別の成績（よくできた分野・苦手な分野）、間違えた論点、以前も間違えた問題（再発）、以前の誤答を正解できた問題（克服）、選んでしまった「危険」な選択肢をまとめ、明日やること（前日の復習・重点分野・計画の課題）を提示。今日の分は回答のたびに更新される途中経過、過去の日はその日の確定した振り返り。
- 手入力の学習時間と振り返りメモは廃止（調子だけは選べる。以前に書いたメモは「以前のメモ」として表示）。

## Edition 10.1 — 演習の一時中断・選んだらまずい度の事前設定

- 資格問題演習に「⏸ 一時中断」を追加。出題順・選んだ選択肢・回答済み・現在位置を保存キー `aaa.practice.paused.v1`（アカウント同期）に保存し、設定画面の「続きから解く」で未回答の問題から再開できる。演習中にページを閉じた・別のタブへ移ったときも自動で保存。「終了」は保存せずに終える。
- Enter キーで次の問題へ移ったときに、問題文に黒い枠（フォーカスの枠）が出ないように修正。
- 選んだらまずい度を、利用者が選ぶ形から、あらかじめ設定した評価の表示に変更（`choice-rate.js`、データは `data/badness/<試験コード>.json`、13 資格・3250 問の不正解の選択肢 9750 件すべてに段階と理由を設定。内訳は危険 1181・不適切 7843・惜しい 726）。不正解の選択肢ごとに「☠ 危険／✕ 不適切／△ 惜しい」と理由を表示し、選んだ選択肢が危険・不適切なら結果の見出しで注意する。

## Edition 10.0 — 連携アニメーションを「一連の流れ」に

- 連携アニメーションの表示を少し小さく（図の最大幅 760px、サービス解説ページでは 680px）。
- サービス図鑑の「○○ の連携」アニメーションを、中心から上下左右へ往復する形から、利用者側から奥へ進む 1 本の流れに変更（`flow.js` の `serviceScene`）。連携先をリクエストの通る順（入口 → API・ロードバランサー → コンピューティング → メッセージング → データ → 分析）に横一列に並べ、隣どうしに実際の連携があるものだけをつなぐ。最後に流れ全体をパケットが通しで流れる。
- 「設定を追加」ステップ: 区間をつなぐ前に必要な設定（連携の詳細の「必要な設定」から OAC・IAM ロール・セキュリティグループ・証明書などを抽出）を、ノードの上に「＋設定」のチップとして積み上げる。
- 「機能を追加」ステップ: IAM・KMS・WAF・ACM・監視などは流れに入れず、あとからサービスに追加する機能として下から登場し、点線でつながる。KMS・IAM などの補助的なサービス自体のページでは、使う側のサービスに順に追加していく流れで表示。
- プレーヤーに段階的な登場（`appear`）・チップ（`chips`）・教材ごとのノード幅（`nodeWidth`）を追加。

## Edition 09.9 — 選択肢の「選んだらまずい度」評価

- 資格問題演習で回答したあと、不正解の選択肢ごとに「△ 惜しい（条件次第で成り立つ）／✕ 不適切（要件を満たさない・過剰）／☠ 危険（セキュリティ・データ損失・可用性を損なう）」を自分で評価できる（`choice-rate.js`）。同じボタンをもう一度押すと解除。
- 選択肢の一覧の上に評価の要約（評価済みの数・段階ごとの数）を表示。評価は保存キー `aaa.choiceRate.v1`（アカウント同期）に保存し、次に同じ問題を解いたときも表示。
- 以前「危険」「不適切」と評価した選択肢を選んでしまったときは、結果の見出しに警告を表示。

## Edition 09.8 — 日ごとの演習記録と「前日の復習」

- 日ごとに解いた問題を記録（`review.js`）。学習計画のページに「日ごとに解いた問題」を追加し、日付ごとに問題・正誤・回答回数を一覧表示。「この日の問題をもう一度」「不正解だった問題だけ」や、1 問ずつの解き直しができる。計画がなくても表示。
- 前日の復習: 毎日、直近の学習日（今日より前で回答がある最後の日）に解いた問題から復習セットを自動作成。①その日に間違えた問題（すべて）②類題（同じ試験・同じ論点の未回答の問題。無ければ同じサービスが登場する問題、最大 10 問）③正解した問題の半分（確認用）。最大 40 問。
- 資格問題演習の設定画面・学習計画の「今日のプラン」・ホームの「今日の学習プラン」に「前日の復習」カードを表示し、「復習を始める / 続きから」で未実施の問題から出題。今日の実施数・正解数を表示。
- 復習セットはその日のうちは変わらないよう保存キー `aaa.review.v1`（アカウント同期）に保存。

## Edition 09.7 — 学習計画（最短合格プラン）と毎日の記録

- サイドバーに「学習計画」（`#plan`、`plan.js` / `plan.css`）を追加。資格・1 日の学習時間・受験予定日（空なら最短）・休みの曜日から、合格までの日別の計画を作る。
- 計画の組み方: ①分野別演習（配点の高い分野から未回答の問題を 1 周、2 日目以降は誤答の復習を 2 割）→ ②弱点復習（誤答の解き直し）→ ③総合演習（受験日まで余裕がある場合）→ ④模試・仕上げ（本番と同じ問題数の模試 → 復習 → 模試 → 最終確認）。今までの回答と正答率を反映し、受験日に間に合わないときは 1 日の問題数を増やして警告、余裕があるときは「最短なら何日に受験できるか」を提示。
- 毎日の記録: 資格問題演習の回答から日ごとの回答数・正答率・新しい問題・解き直し・計画の達成度を自動集計。学習時間・調子・振り返りメモを手入力（自動保存）。カレンダーで達成度を色分けし、過去の日の記録も見直し・編集できる。
- 各課題の「はじめる」から、その課題の問題（未回答・誤答・配点比率どおりの模試など）で資格問題演習を開始。
- 推定得点率（分野ごとの直近回答の正答率 × 配点比率）と合格目安、計画どおりのペース、連続学習日数を表示。ホームに「今日の学習プラン」カード。
- 計画を作ると、資格と受験予定日を取得目標（`aaa.goal.v1`）にも反映。保存キー `aaa.plan.v1` を学習データに追加（`account.js` の KEYS）し、アカウントに同期。計画を作り直しても過去の日の計画と記録は残る。

## Edition 09.6 — 取得目標の資格

- 取得目標の資格（最大 3 つ）と受験予定日を設定できる（`goal.js` / `goal.css`、学習データ `aaa.goal.v1` としてアカウントに同期）。ホームの「🎯 取得目標の資格」カードと、資格問題演習の設定画面の上のバーから設定・変更。
- 資格問題演習で「目標の資格に集中」（既定でオン）にすると、資格の選択肢が目標の資格だけになり、既定で「目標の資格すべて」（目標が1つならその資格）を出題。分野・出題確率・実試験と同じ問題数・試験の概要も目標の資格に合わせる。オフにすると全資格から選べ、目標の資格には 🎯 が付く。
- 取得済みの資格も登録できる（設定ダイアログで資格ごとに「— / 🎯 目標 / ✅ 取得済み」を選ぶ。取得済みは受験終了した旧版も選べる）。ホームのカードに「✅ 取得済み」として表示し、演習の資格一覧（集中オフ時）では ✅ を付ける。
- ホームのカードに目標ごとの実施状況（実施した問題数 / 問題数）と受験までの日数を表示。カードの資格を押すとその資格の演習へ。

## Edition 09.5 — メモ機能
