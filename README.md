# AWS Architecture Academy — Step 1

日本語の AWS 学習サイトの基本版。依存パッケージ不要の HTML / CSS / JavaScript です。

## 起動

```sh
cd /workspace/aws-architecture-academy
python3 -m http.server 3300 --bind 127.0.0.1
```

ローカルブラウザでポート 3300 を開いてください。JSON を fetch するため、ファイルの直接オープンでは動作しません。クラウド内の localhost は外部公開 URL ではありません。

## 構成

- index.html: ダッシュボード、図鑑、教材プレイヤー、ロードマップ、履歴
- style.css: レスポンシブ表示と light/dark/system
- script.js: 検索・絞込・SVG 教材再生・手動学習記録
- data/scenes.json: 添付仕様の PX-02 / HC-01 / LB-01 を抜粋
- assets/: 添付パッケージの独自 SVG 素材
- docs/: 抽出要件、採用判断、検証結果

## 実装範囲

9 件の図鑑、3 件のステップ教材（再生/停止/前後/先頭/速度/シーク）、実際に記録した学習履歴、4 段階のロードマップを実装。reduced-motion では再生ボタンで静的に1ステップずつ進みます。

比較、構成シミュレーター、障害ラボ、問題演習、認証・管理画面、API、DB、IndexedDB、密度切替は未実装です。全仕様完成版ではありません。

教材はドラフトです。AWS 公式ドキュメントへの参照を掲載していますが、最新版との照合・専門レビューは未実施です。図・時刻・数値は教育用モデルであり、実環境操作や課金はありません。学習記録は基本版専用 localStorage に保存し、習熟度や試験の得点は推定しません。

## 公開

相対 URL とハッシュナビゲーションを使い、GitHub Pages のサブパス配信に対応する構成です。Step 2 で main ブランチの Git リポジトリを初期化し、初回コミットを作成します。Push、Pages 設定は未実施です。静的サイトには本物のパスワード保護や秘匿した採点処理を実装できません。必要な場合はサーバー実行型の配信先へ切り替える設計が必要です。
